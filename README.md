# AI Data Classification Using KNN
## Description
This project demonstrates a basic classification model using the Iris Dataset and the K-Nearest Neighbors (KNN) algorithm.
The model is trained to classify iris flowers into different species based on their features such as sepal length, sepal width, petal length, and petal width.

## Technologies Used

* Python
* Scikit-Learn
* NumPy
* Pandas

## Features

* Dataset Loading
* Data Preprocessing
* Train-Test Split
* Feature Scaling
* KNN Classification
* Accuracy Evaluation
* Confusion Matrix
* Classification Report

## How to Run

1. Install required libraries:

pip install scikit-learn pandas numpy

2. Run the Python file:

python classification.py

3. View the model accuracy and classification results.
